magical operations:



Goal: We wanted to create a game inspired by "Magic the Gathering", with simplified logic, to learn object oriented programming, practice working as a team, and learn C++.



Result: I learned to importance of communication and planning between team members, with weekly or biweekly meetings discussing progress and the goals for the upcoming weeks. Class structure and importance of clean code for simple understanding between team members. Receiving and giving constructive criticism. Additionally we implemented AI behavior for an opponent, learning how to let the system recognize preferred outcomes and automate the steps it needed to take for it.
